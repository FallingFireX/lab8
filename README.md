## Lab Questions

### In plain English describe the function and use of a multiplexer.
A multiplexer chooses one signal from several inputs and sends it to a single output. If you have 4 input signals for example A, B, C, D, the multiplexer lets a control signal choose one of them and send that signal to the output.

### In plain English describe the function and use of a demultiplexer.
A demultiplexer does the opposite job of a multiplexer. It takes one input signal and sends it to one of several outputs, depending on control signals. If there are 4 outputs, the select lines decide which one gets the input signal.

### What other uses might these circuits have? (Think Shannon’s)
multiplexers and demultiplexers can be used to implement any Boolean logic function, including AND, OR, XOR, etc. So, the data inputs can be set to 0 or 1 so that the multiplexer produces the correct output for a Boolean function.
